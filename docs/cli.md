# CLI Reference

!!! info "Usage"

    The CLI uses [tyro](https://brentyi.github.io/tyro/):

    - Positional arguments ("required") are passed as positional command line arguments
    - Named arguments are passed as flagged command line arguments
    - Run `jjh <command> --help` for the full list of options for each command

## `jjh version`

        heading_level: 2
